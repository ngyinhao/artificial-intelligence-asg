# Official CFPB complaint API returned HTTP 403

- **Date:** 2026-07-11
- **Context and intended action:** Validate the implemented official CFPB API query with one narrative record before downloading the project dataset.
- **Observable symptom:** The documented endpoint returned `403 Client Error: Forbidden` for a bounded narrative/product/date request. The URL and parameter names matched the current official OpenAPI specification.
- **Impact:** The API-backed downloader cannot collect the approved dataset from this execution environment until the access policy or request shape is corrected.
- **Confirmed cause:** The CFPB Akamai edge service denies GET requests from this environment. Retrying with browser-oriented `User-Agent`, `Accept`, and `Referer` headers and the documented minimum offset still returned an `Access Denied` page. This is independent of the API query contract.
- **Troubleshooting results:** The official ZIP and uncompressed CSV hosts both respond successfully. The uncompressed CSV is approximately 8.9 GB and advertises byte-range support; two bounded range requests returned HTTP 206 as expected. Records are not ordered by received date, so a simple prefix download is invalid.
- **Successful workaround:** The downloader now tries the documented API first and automatically falls back on HTTP 403 to deterministic, non-overlapping byte ranges from the official CSV. It filters the approved period/categories, stops after every class has a sufficient candidate pool, and records all ranges in the manifest.
- **Remaining limitation:** Byte-range sampling is deterministic and bounded but is not equivalent to a uniform sample of all CFPB records. This must remain documented as a source limitation.
